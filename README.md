# SmartExpense-Automated-Tracking-Daily-Budget-Advisor
SmartExpense is a mobile-friendly personal expense tracker designed to help you understand where your money goes, stay within your budget, and build better spending habits.

The project started from a common problem: forgetting to record purchases and only realizing later how quickly money has been spent. SmartExpense aims to make tracking expenses easier and provide clear daily, weekly, and monthly summaries.
Current status: SmartExpense is a front-end prototype. Transactions are stored in the browser on the device where the app is used. Automatic reading of Touch 'n Go eWallet or bank notifications is not implemented in this version.

## Features
- Dashboard: View your spending and budget information in one place.
- Daily, weekly, and monthly summaries: Review recorded expenses and income over different periods.
- Daily spending guidance: Estimate how much of your available budget remains for the day.
- Expense and income entries: Add transactions manually.
- Demo transaction flow: Add sample transactions to preview how transaction tracking works.
- Transaction history: Review transactions recorded in the app.
- Monthly budget settings: Set or adjust your budget.
- Local data storage: Save transactions in the browser using localStorage, so they remain available in that browser unless its site data is cleared.
